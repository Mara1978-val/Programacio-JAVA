# 🔑 Soluciones 26/27 {.page-title}

::: danger-box Material del profesorado
Esta página y las soluciones que enlaza **no se publican en el sitio del alumnado**.
`config.mts` las excluye del build con `srcExclude`, así que sus páginas no existen
en `docs/`, no aparecen en el mapa de rutas del router ni en `hashmap.json`.

Solo son visibles ejecutando el build del profesorado:

```bash
npm run dev:profesorado     # servidor local con soluciones
npm run build:profesorado   # build completo con soluciones
```

No enlaces esta página desde ningún contenido del curso ni la pegues en un aula
virtual: si el sitio del profesorado llegara a servirse sin control de acceso
delante, cualquiera con el enlace entraría.
:::

::: info-box Si quieres las soluciones accesibles online
La vía robusta no es ocultar la ruta, sino autenticar. Despliega el build del
profesorado en un hostname aparte protegido con Cloudflare Access (el mismo
patrón que usa `introduccion-laravel`, con `functions/_middleware.js` cerrando
los dominios `*.pages.dev`). Access valida la identidad **antes** de servir el
asset, así que ni el HTML ni el mapa de rutas salen a Internet sin login.
:::
