# 🔑 Solucions 26/27 {.page-title}

::: danger-box Material del professorat
Aquesta pàgina i les solucions que enllaça **no es publiquen en el lloc de l'alumnat**.
`config.mts` les exclou del build amb `srcExclude`, de manera que les seues pàgines no
existixen en `docs/`, no apareixen en el mapa de rutes del router ni en `hashmap.json`.

Només són visibles executant el build del professorat:

```bash
npm run dev:profesorado     # servidor local con soluciones
npm run build:profesorado   # build completo con soluciones
```

No enllaces aquesta pàgina des de cap contingut del curs ni la pengeu en una aula
virtual: si el lloc del professorat arribara a servir-se sense control d'accés
davant, qualsevol amb l'enllaç hi entraria.
:::

::: info-box Si vols les solucions accessibles en línia
La via robusta no és ocultar la ruta, sinó autenticar. Desplega el build del
professorat en un hostname a banda protegit amb Cloudflare Access (el mateix
patró que fa servir `introduccion-laravel`, amb `functions/_middleware.js` tancant
els dominis `*.pages.dev`). Access valida la identitat **abans** de servir
l'asset, així que ni l'HTML ni el mapa de rutes ixen a Internet sense login.
:::
