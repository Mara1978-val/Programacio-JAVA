## Descripció del mòdul

El mòdul de **Programació** recorre el camí complet des de què significa programar fins a construir aplicacions Java amb persistència de dades i interfície gràfica. Cada unitat formativa afig una peça: primer el pensament algorítmic, després la sintaxi del llenguatge, més tard les estructures de dades, l'orientació a objectes i, finalment, la connexió amb el món exterior (fitxers, bases de dades i interfícies gràfiques).
