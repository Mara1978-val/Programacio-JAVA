# UF3.1 Introducció a la Programació I

<!--@include: @/_partials/info-modul.md-->

::: info Síntesi de la unitat
Aquesta unitat té com a objectiu introduir-vos a les principals eines utilitzades en el desenvolupament de programari. Coneixereu els diferents tipus d'entorns de desenvolupament (IDEs), aprendreu a instal·lar extensions útils, a gestionar projectes i a depurar el codi de manera eficient. A més, explorareu el control de versions per a treballar de forma organitzada i col·laborativa, i seguireu guies pràctiques per començar a programar amb entorns com Visual Studio Code.
:::

## 📋 Objectius del Curs {.animate-title}

::: tip Objectius cuberts i relació amb RA

Aquest tema se centra en l'ús d'eines professionals que faciliten la creació i la gestió de projectes de programari.

- Objectiu 3.1: Instal·lar i configurar un entorn de desenvolupament integrat (IDE).
- Objectiu 3.2: Crear, compilar i executar projectes bàsics en un IDE.
- Objectiu 3.3: Utilitzar eines de depuració per a identificar i corregir errors en el codi.
- Objectiu 3.4: Manejar les funcionalitats bàsiques d'un sistema de control de versions.

## 🔗 Recursos addicionals {.animate-title}

- [Visual Studio Code](https://code.visualstudio.com/)  
Editor de codi font obert amb una gran quantitat d'extensions per a suportar diversos llenguatges de programació, incloent Java.
- [NetBeans IDE](https://netbeans.apache.org/front/main/download/index.html)  
Entorn de desenvolupament integrat recomanat per programar en Java, amb suport per a projectes modulars i interfícies gràfiques.
- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/)  
Kit de desenvolupament Java necessari per compilar i executar programes. Es recomana la versió més actual (o, en tot cas, 11 o superior).
- [Git](https://git-scm.com/)  
Sistema de control de versions distribuït que permet gestionar projectes de programari de manera eficient.
