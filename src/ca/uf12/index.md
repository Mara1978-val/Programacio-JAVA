# UF12. Interfícies gràfiques

<!--@include: @/_partials/info-modul.md-->

::: info Síntesi de la unitat
* **Interfícies i Components:** Evolució de CLI a Web utilitzant elements modulars d'entrada, acció, informació i dades.
* **Arquitectura MVC:** Separació fonamental entre Model (dades), Vista (visual) i Controlador (lògica) per a un codi mantenible.
* **Ecosistema Java:** Coexistència de tecnologies d'escriptori (Swing/JavaFX) amb l'estàndard actual de servidor (Spring Boot).
* **Mercat Laboral:** Predomini del desenvolupament Web/API i un gran volum de manteniment de sistemes corporatius heretats.
:::

## 📋 Objectius del Curs {.animate-title}

::: tip Objectius cuberts i relació amb RA

Aquest tema aborda els conceptes actuals sobre com es creen interfícies gràfiques d'usuari (GUI) en aplicacions modernes.

* **Objectiu 12.1:** Reconèixer les possibilitats d'entrada/eixida del llenguatge i les llibreries associades per a la creació d'interfícies (CLI, GUI i Web).
* **Objectiu 12.2:** Utilitzar les ferramentes de l'entorn de desenvolupament per a dissenyar i crear interfícies gràfiques d'usuari simples basades en components.
* **Objectiu 12.3:** Programar controladors d'esdeveniments per a gestionar la interacció de la persona usuària amb els components d'acció de la interfície.
* **Objectiu 12.4:** Desenvolupar programes que utilitzen interfícies gràfiques (vistes) per a l'entrada de dades i la visualització de la informació (model).

---

| Criteri d'Avaluació | Objectius Didàctics |
| :--- | :--- |
| **RA05.f**: S'han utilitzat les ferramentes de l'entorn de desenvolupament per a crear interfícies gràfiques d'usuari simples. | **Objectiu 12.3** |
| **RA05.g**: S'han programat controladors d'esdeveniments. | **Objectiu 12.4** |
| **RA05.h**: S'han escrit programes que utilitzen interfícies gràfiques per a l'entrada i eixida d'informació. | **Objectiu 12.5** |

:::
